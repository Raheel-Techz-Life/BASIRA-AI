# Methodology — Educational Baseline Demo

**Scope note:** this describes the *implemented* existing-tumor
classification pipeline, not the future-risk research task (which has no
dataset — see `docs/dataset_feasibility.md`). Results below are filled in
once training actually completes; nothing here is assumed in advance.

## Data

- Source: Kaggle "Brain Tumor MRI Dataset" (masoudnickparvar), combining
  Figshare, SARTAJ, and Br35H sources. DOI: 10.34740/KAGGLE/DSV/1183165.
- Classes: `glioma`, `meningioma`, `pituitary`, `notumor`.
- Training split: 1,400 images/class (5,600 total).
- Testing split (held out, untouched until final evaluation): 400
  images/class (1,600 total).
- No patient identifiers are provided by this dataset (see
  `docs/limitations.md`, item 1).

## Pipeline

1. **Manifest + validation** (`src/data/dataset.py`): every file is opened,
   format-checked, and size-checked before use; invalid files are flagged
   in the manifest rather than silently dropped.
2. **Preprocessing** (`src/data/preprocessing.py`): grayscale conversion,
   resize to 128x128, per-image min-max intensity normalization. Identical
   function used at training and inference time.
3. **Feature extraction** (`src/data/feature_extraction.py`): 12 features —
   5 intensity statistics, 4 GLCM texture measures, 3 simple morphology
   measures (Otsu foreground fraction + centroid offset). See that file's
   docstring for the justification of each family.
4. **Model selection** (`src/models/train.py`): features are standardized
   (fit on training data only), then a stratified 80/20 image-level
   train/validation split is used to compare:
   - Majority-class baseline
   - Logistic Regression
   - Random Forest (200 trees)
   - SVM (RBF kernel)
   The best model by macro-F1 on validation is retrained and evaluated once
   on the held-out Kaggle Testing split.
5. **Evaluation** (`src/evaluation/metrics.py`): accuracy, macro-F1,
   per-class precision/recall/F1, confusion matrix. Accuracy alone is never
   reported, per the master prompt's evaluation rules.
